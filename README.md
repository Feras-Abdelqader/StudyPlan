# StudyPlan 📚

A cross-platform Flutter application designed to enhance student productivity with dynamic focus timers, personalized account settings, and clean UI navigation.

---

## ✨ Features
* ⏱️ **Focus Timer:** Dynamic Pomodoro countdown powered by Flutter `AnimationController`.
* 🔐 **Authentication:** Dedicated Sign-Up and Login interfaces.
* 🧭 **Navigation Drawer:** Centralized routing across all screens.
* ⚙️ **User Preferences:** Real-time state toggles for app notifications and sound settings.

---

## 🛠️ Tech Stack
* **Framework:** Flutter (Dart)
* **UI Design:** Material Design 3
